\section{Objetivo}
Consolidar o aprendizado das tecnologias fundamentais da web através da aplicação prática dos recursos abordados nos roteiros: estruturação semântica, estilização avançada com \textbf{Flexbox}, uso estratégico de \textbf{Classes e IDs} para personalização CSS e implementação de interatividade dinâmica via \textbf{JavaScript}.

\section{Orientações e Requisitos de Construção}
\begin{itemize}
    \item \textbf{Estrutura de Conteúdo:} A página deve ser organizada em no máximo \textbf{4 seções principais}, respeitando até \textbf{3 níveis de profundidade} hierárquica.
    \item \textbf{Formulário Obrigatório:} É indispensável a inclusão de ao menos um \textbf{formulário funcional} para inscrição, solicitação de serviços ou inclusão de dados (utilizando diversos tipos de \texttt{input}).
    \item \textbf{Navegação:} Inclusão de um menu superior (Navbar) com opções de navegação interna ou entre páginas.
    \item \textbf{Estilização:} Uso de modelos baseados em \textbf{Cards} para apresentação de informações, garantindo organização visual.
\end{itemize}

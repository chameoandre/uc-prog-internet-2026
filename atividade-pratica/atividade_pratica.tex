\section{Objetivo}
O objetivo desta atividade é consolidar o aprendizado das tecnologias front-end (\textbf{HTML, CSS e JS}) através do desenvolvimento de uma interface completa, responsiva e funcional. Os estudantes deverão aplicar conceitos de semântica, layouts modernos (Flexbox/Grid) e manipulação do DOM.

\section{Orientações e Requisitos}
\begin{itemize}
    \item \textbf{Formato:} Duplas (ou trios, sob consulta).
    \item \textbf{Versionamento:} Repositório no GitHub obrigatório para a dupla.
    \item \textbf{Tecnologias:} Proibido o uso de frameworks CSS (Bootstrap, Tailwind). Foco em Vanilla CSS.
    \item \textbf{Responsividade:} A interface deve ser \textit{Mobile-First}.
\end{itemize}

\section{Sugestões de Temáticas}

Escolha um dos grandes temas abaixo. Você pode optar por uma das sub-temáticas sugeridas ou propor algo similar dentro do tema:

\begin{enumerate}[label=\textbf{Tema \arabic*:}, leftmargin=2cm]
    \item \textbf{Turismo e Lazer (Foco Garopaba)}
    \begin{itemize}
        \item Sub 1: Site institucional de Pousada com sistema de reserva de quartos.
        \item Sub 2: Guia de Trilhas e Natureza com mapas e dicas de preservação.
        \item Sub 3: Portal do Surf local (previsão, escolas e campeonatos).
    \end{itemize}

    \item \textbf{E-commerce e Catálogos Profissionais}
    \begin{itemize}
        \item Sub 1: Loja de Cafés Especiais com carrinho e filtros de grãos.
        \item Sub 2: Catálogo de Livraria Independente com busca dinâmica.
        \item Sub 3: Artesanato local com galeria de fotos e pedidos via WhatsApp.
    \end{itemize}

    \item \textbf{Serviços, Saúde e Bem-estar}
    \begin{itemize}
        \item Sub 1: Clínica Veterinária com agendamento de consultas.
        \item Sub 2: Landing page para Spa ou Estúdio de Yoga.
        \item Sub 3: Portal de Nutrição com calculadora de IMC ou planos de dieta.

    \item \textbf{Painéis e Dashboards de Dados (JS Intensivo)}
    \begin{itemize}

        \item Sub 2: Painel de Smart Home (monitoramento de temperatura/luzes).
        \item Sub 3: Monitor de Treinos de Academia (histórico e metas).
    \end{itemize}

    \item \textbf{Portfólios e Branding Pessoal}
    \begin{itemize}
        \item Sub 1: Portfólio de Fotógrafo com galeria filtrável por categoria.
        \item Sub 2: Site de Freelancer Tech com currículo e formulário de contato.
        \item Sub 3: Landing Page para lançamento de App Mobile ou SaaS.

    \item \textbf{Gastronomia e Alimentação}
    \begin{itemize}
        \item Sub 1: Cardápio Digital Interativo para Hamburgueria.

    \item \textbf{Social, Educação e Comunidade}

    \begin{itemize}

\section{Critérios de Avaliação}
\begin{boxAtividade}[Checklist de Entrega]
\begin{itemize}
    \item \textbf{Semântica (2.0):} Uso correto de \texttt{nav, main, section, footer, article}.
    \item \textbf{Design CSS (3.0):} Uso de Flexbox/Grid, variáveis, cores e tipografia harmônica.
    \item \textbf{Responsividade (2.5):} Funcionamento impecável em celular e desktop.
    \item \textbf{Interatividade JS (2.5):} Manipulação do DOM (ex: filtros, modais, validações).
\end{itemize}
\end{boxAtividade}
